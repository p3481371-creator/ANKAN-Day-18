# ANKAN · अंकन

Concept website for a luxury Indian writing-instrument house.

- Scroll film: a Bidri fountain pen turns, comes apart into its six parts, and reassembles (366 frames on canvas)
- The nib being ground by hand, on a loop
- A test sheet to try six nib grinds (extra fine to italic)
- Type a name and a gold nib writes it in ink (Sona, Neel, Sindoor, Kesar)
- Six crafts collection, nib anatomy, karigar story, commission form

Open `index.html` through any static server.

Concept website · sample products and prices · not a real store
